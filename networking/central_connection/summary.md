# Central connection example
## Objective
  - Simulates a scenary where 3 states are connected to the central main hub
## Structure
  - Uses RIPv2, IPv4 private and public address, subneting without classes
  - Some WAN connections uses same IPv4 base
  - LAN connections use private address base 10.0.0.0
  - All WAN connections go to the central hub
  - Only uses routers and PC's
